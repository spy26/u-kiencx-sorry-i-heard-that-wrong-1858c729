A smart speaker apologizes to its owner after mishearing "call Mom" — and dialing the mother-in-law instead. One line, 134 characters.

## Run it

```sh
node main.ts
```

This validates the one-line entry (exactly one line, at most 140 characters, no empty lines or extra spaces), writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (and to `/output/entry.txt` if it can be written), verifies each written file byte-for-byte against the entry, and prints the text to stdout.
